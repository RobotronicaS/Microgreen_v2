# Registro de usuarios de Consulta

Cada persona elige su propio usuario y contraseña. El administrador autoriza los invernáculos que puede visualizar. La cuenta se habilita al recibir esa autorización.

## Para quien se registra

1. Conectá Tailscale en tu computadora o celular. El equipo debe tener acceso a la red privada de Central.
2. Abrí el enlace de Central que te compartió el administrador.
3. En **Ingresar a Central**, pulsá **Registrarse**.
4. Completá nombre y apellido, usuario y contraseña. Repetí la contraseña. El usuario debe tener entre 3 y 40 letras minúsculas, números, puntos, guiones o guiones bajos. La contraseña debe tener al menos 12 caracteres.
5. Pulsá **Registrarme**. Cuando aparezca **Registro recibido**, avisale al administrador para que revise tu solicitud.
6. Una vez autorizado, volvé a **Ingresar** y usá el usuario y la contraseña que elegiste.

La cuenta tiene el rol **Consulta**. Permite ver los invernáculos autorizados, sus cámaras, fotografías e historial y los datos disponibles de esos sitios. Las funciones de configuración y administración requieren otros permisos.

## Para el administrador

1. Ingresá con tu cuenta administradora.
2. Abrí **Administración → Registros pendientes**. El inicio también muestra un acceso cuando hay solicitudes nuevas.
3. Identificá a la persona por su nombre y usuario.
4. Marcá los invernáculos que puede visualizar. Si hay uno solo, aparece seleccionado.
5. Pulsá **Autorizar consulta**. La persona ya puede ingresar con su contraseña.
6. Para descartar una solicitud, pulsá **Rechazar**. Podrá volver a enviar un registro.

Cada solicitud se autoriza como Consulta. Los registros no pueden elegir permisos de Técnico ni de Administrador. Si más adelante necesitás retirar un acceso, usá **Permisos por sitio → Retirar acceso**. Para suspender toda la cuenta, usá **Suspender** en la lista de cuentas.

## Versión activa

El encabezado muestra **v0.8.0** en la pantalla de ingreso y en la portada una vez instalada esta versión. El dato se toma del programa que está ejecutando Central y coincide con el valor de `/salud`.

Si todavía aparece una versión anterior, comprobá que terminó la instalación y actualizá la página. En Windows podés usar **Ctrl+F5**. Desde el celular, volvé a abrir el enlace de Central.
